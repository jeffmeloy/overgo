How to read a row.

A lane's run is a reach class and the lane's own seconds.
After an at sign come the numbers of the packages the commit's changed paths reached the lane through.

A row names the strongest class among the commit's changed paths, in that order.
A stop at a package cuts a run when no changed path reaches the lane once the lane's closure neither holds that package nor descends into it.
